# Infographic

## Planning

- Select only source-supported headline facts, numbers, categories, and takeaways. Organize them into a clear reading sequence rather than a dense graph.
- Plan a title/hero idea, a small number of balanced cards or sections, and concise supporting labels. Do not manufacture statistics or comparative claims.
- Use connectors only when sequence or causality matters; otherwise rely on alignment, grouping, numbering, and visual hierarchy.

## XML generation

- Use a clean grid of cards, bands, callouts, and simple semantic shapes. Emphasize key values through scale and typography while keeping explanatory text readable.
- Reuse one palette and component style across sections. Avoid decorative icons without exact context and avoid turning every sentence into a separate box.
- Keep the composition presentation-ready with generous whitespace, aligned section edges, and no unnecessary connector layer.
