# Mind map

## Planning

- Put one central concept at the center, then derive a strict branch/sub-branch hierarchy from the source.
- Use short labels. Assign one consistent color family to each primary branch and inherit that family for descendants.
- Do not create cross-branch links unless the source explicitly describes them; hierarchy is the primary relationship.

## XML generation

- Use a radial composition with a prominent central node, evenly distributed primary branches, and progressively smaller descendants.
- Use curved or straight arrowless branch connectors consistently; avoid orthogonal flowchart arrows.
- Keep labels inside nodes, preserve branch colors, and leave enough angular separation that sub-branches do not collide.
