# Timeline

## Planning

- Sort only source-supported events and milestones chronologically. Preserve uncertainty and do not invent dates or durations.
- Group multiple events under the same date/period. Use proportional spacing only when the intervals are reliable; otherwise use even readable spacing.
- Choose a horizontal axis for a modest event count and a vertical axis when labels are long or numerous.

## XML generation

- Draw one clear axis with consistent milestone markers and short dated labels. Alternate annotations across the axis only when needed to prevent overlap.
- Use straight, arrowless axis/leader lines and a restrained color system for eras or categories. Do not represent the timeline as a chain of process arrows.
- Keep chronological order visually unambiguous and align same-period events without duplicating the date unnecessarily.
